3 Injection Depths
🐧
Depth 1 — OS / Kernel
tc netem · stress-ng · pkill · systemctl · docker
Requires: Linux target + sudo
🔌
Depth 2 — HTTP Proxy
Local MITM proxy intercepts LLM API calls
Point SDK at localhost:<port>
🩹
Depth 3 — Transport Patch
Monkey-patches httpx.Client.send + requests.Session.send
Works on any OS · no port · no sudo
